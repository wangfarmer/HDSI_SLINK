# HDSI_SLINK

Research workspace for HUMA.I.N S-Link data collection and grouping experiments.

## Current focus

Requirement 2 is implemented as a configurable Harvard faculty scraper scaffold:

- Built-in configs for several Harvard school faculty directories.
- Profile URL discovery from school directory pages.
- Profile extraction for name, title, affiliation, email, image, bio, and research interests.
- JSONL/CSV output for later ORCID merge and S-Link grouping experiments.

See `docs/harvard_faculty_scraper.md` for usage.
